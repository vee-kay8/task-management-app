# Next Steps: GCP Exploration

This document outlines a potential path to compare Azure deployment with GCP.

## Suggested Phases

1. GCP account setup and billing
2. Networking (VPC, subnets, firewall rules)
3. Cloud SQL for PostgreSQL
4. Artifact Registry
5. Cloud Run or GKE for services
6. Secret Manager integration
7. Monitoring (Cloud Monitoring + Logging)
8. CI/CD (Cloud Build or GitHub Actions)
9. Cost optimization
10. Final comparison report

## Mapping (Azure → GCP)

| Azure | GCP |
|-------|-----|
| VNet | VPC |
| Container Apps | Cloud Run / GKE |
| ACR | Artifact Registry |
| PostgreSQL Flexible Server | Cloud SQL for PostgreSQL |
| Key Vault | Secret Manager |
| Azure Monitor | Cloud Monitoring + Logging |
